### 必须补实的动态分析

现有汇总主题热图与层次聚类描述的是总体语义关系，不能直接证明主题的跨阶段变化。建议优先核对“专利编号—年份—IPC—主题编号”的逐条映射，在可比的主题定义下计算各阶段主题占比、代表文本和语义特征，再与节点影响力变化对照。可以研究采用统一主题模型后按时间汇总；如采用各阶段独立模型，须另行说明主题对齐方法。这些属于拟补充分析，不能写作已完成结果。

主题强度须明确分母是阶段全部有效专利还是筛选后的主题样本；多标签、噪声主题、跨主题重复及阶段长度差异须采用一致统计口径。语义变化须有阶段文本支撑，不能从主题频数上升直接推出技术突破或工程成熟。

第3章现有描述时段与网络时段存在边界差异（描述分析为2010—2013、2014—2019、2020—2025；网络分析为2010—2014、2015—2019、2020—2025）。本轮不修改第3章；第4章应说明差异和采用依据。若最终要求窗口完全一致，需要另行统一数据计算，不能只更换年份标签。

## 3. 第4章输出、第5章接收的证据包

4.5.3负责形成原始分析成果的标准化证据包，建议同时保存可读表格和JSON。以下仅定义字段，不虚构任何实际技术记录。

| 字段组 | 必需内容 |
|---|---|
| 对象身份 | 技术对象ID、名称、主题定义、关键/潜在关键技术分类及筛选依据 |
| 数据关联 | IPC节点、专利编号、主题编号、可追溯的代表文本或原文定位 |
| 时间与阶段 | 数据截止日、网络分析窗口、领域生命周期背景；单项技术生命周期如未单独测定，填写“未独立判定” |
| 网络证据 | 各阶段影响力指标、变化方向、计算口径、对应表格/记录位置 |
| 主题证据 | 阶段样本数、占比和分母、关键词/代表文本、主题对齐及语义变化依据 |
| 关联与协同 | 关联技术、共现或语义依据、拟解释的工程功能；区分观察关系与条件性工程解释 |
| 瓶颈线索 | 已提供材料中实际观察到的限制、对应文本及来源；未观察到时保留缺失，不由模型补作历史事实 |
| 判断边界 | 可直接支持的判断、需要额外假设的推断、当前不能支持的结论、缺失材料 |
| 追溯与版本 | 证据ID、来源文件/表格/段落、统计口径、生成记录、版本及时间 |

不能把领域总体生命周期阶段直接赋给每一项技术。第3章只有领域拟合时，证据包中的阶段信息应写成领域背景；技术自身的成熟度、TRL和商业化时间另需证据。

### 多智能体与harness的分工

本研究拟将多智能体用于不同职责的推理与审查，将harness具体定义为包围这些任务的状态管理、输入与输出约束、证据检查、修正及终止机制。LangGraph是拟采用的流程编排基础，不单独作为预测算法或创新贡献。

| 角色 | 输入与任务 | 输出 |
|---|---|---|
| 演化分析 | 读取第4章证据包，区分观察趋势、限制和缺失项 | 带证据ID的演化摘要 |
| 发展命题生成 | 依据摘要和明确假设提出发展方向 | 候选命题、时域、证据引用、实现条件 |
| 反向审查 | 检查竞争解释、相反证据和论断越界 | 逐命题异议及问题定位 |
| 工程评审 | 检查场景依赖、实施条件和成熟度证据 | 条件清单与工程证据缺口 |
| 综合裁决 | 对照原证据及审查意见保留、修改或暂缓命题 | 结构化结论及未解决分歧 |

工程评审智能体属于模型角色，不等同于真实工程专家评价。各角色可以使用相同基础模型，须通过任务、上下文和输出责任区分，而非仅增加调用数量。

5.3拟规定：固定输入版本；共享状态和逐命题编号；原始证据只读；检查引用ID、数值与时间边界；保留异议；有限次数修正；正常完成、材料不足和次数耗尽分别终止；输出记录来源、假设、支持程度和缺口；保留运行日志。具体循环上限、置信分级规则、模型及提示词版本须在实验前确定。

证据支持等级不能直接解释为未来事件发生概率。格式校验、多个角色同意和模型自评分也不能代替实证验证。

### 第5章结果与评价的最低要求

每条最终结论至少包括：命题ID、技术对象ID、时域、发展判断、证据ID、推理依据、实现条件、竞争解释、证据支持等级和待补材料。

5.5.1的历史一致性用于检查结论是否背离输入及已观察事实，本身不能证明未来预测准确。若开展历史回测，须预先确定时间切分，排除输入中的未来信息，并披露基础模型可能已接触后期知识的限制。

附件5.5.2使用“单模型与多智能体”标题。为使比较可解释，建议操作上定义为：同一基础模型、同一证据包、相同预测任务下的单智能体流程与多智能体流程，并控制或报告调用次数、token与时间预算。角色数量不是模型数量；后续标题可进一步规范为“单智能体与多智能体方法的对照分析”，本轮仍保留附件原题。

拟评价证据引用正确性、无支持命题比例、条件完整性、结果稳定性和运行成本；如需检验harness的贡献，可增加保持角色不变、减少指定约束的消融。评价规则、重复次数和人工评阅方法须事前确定，不虚构指标、得分或专家意见。
